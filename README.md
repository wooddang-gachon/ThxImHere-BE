# git branch 전략

개인이 진행하는 프로젝트이기 때문에 깃 branch 전략은 간단하게 진행하기로 한다.
주로 main, develop를 사용하고 release는 개발 완료 후 qa 및 완성품을 확인하기 위한 branch이다.

- main : 기준이 되는 브랜치로 제품을 배포하는 브랜치
- develop : main애서 branch해 기능 개발을 진행한다.
- release : 배포를 위해 master 브랜치로 보내기 전에 먼저 QA(품질검사)를 하기위한 브랜치
